# NaNTech - Frontend Development Tasks 🚀

Bu repozitoriya mənim Frontend inkişafı yolunda hazırladığım kiçik və orta həcmli layihələrdən ibarətdir. Burada ümumilikdə 24 fərqli tapşırıq toplanmışdır.

## 🛠 Texnologiyalar
* **HTML5** & **CSS3** (Responsive Design, Flexbox, Grid)
* **JavaScript** (ES6+, DOM Manipulation, Array Methods)

## 📂 Layihələrin Siyahısı

Aşağıda əsas tapşırıqların bəziləri və onların qısa təsviri verilmişdir:

| Layihə Adı | Təsvir | Texnologiya |
| :--- | :--- | :--- |
| **Worker Management** | İşçilərin siyahısı və idarə olunması sistemi | JS (Array Methods) |
| **Mini E-Commerce** | Məhsul səbəti və alış-veriş simulyasiyası | JS / DOM |
| **Table Tasks** | Dinamik cədvəllər və filtrləmə | JS |
| **Todo List** | Gündəlik tapşırıqların idarə edilməsi (Zero & One based) | JS / LocalStorage |
| **Analog & Digital Clock** | Real vaxt rejimində işləyən saatlar | JS / CSS |
| **Landing Pages** | Müxtəlif mövzularda (Cake Shop, Spacial) səhifələr | HTML / CSS |
